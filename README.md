# Bytherix Backend API

API documentation: [https://bytherix-cjlv.onrender.com/api/v1/api-docs](https://bytherix-cjlv.onrender.com/api/v1/api-docs)

## Getting Started

### Installation

```bash
npm install
```

### Database Seeding

To seed the database with initial test data (Roles, Permissions, Categories, Users, User Profiles, Instructors, Courses, Enrollments, and Contacts):

```bash
npm run db:seed
```

### Running the Application

```bash
npm run dev
```
